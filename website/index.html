Direct Kernel Architecture

No Cgo wrappers, no bloated daemon layers, no external agents. How Statix streams telemetry from kernel VFS to your browser.

01

Kernel /proc and /sys

Direct unbuffered reads from Linux virtual filesystem descriptors. Zero C bindings and zero reflection overhead.

Zero-Copy Go Parsers

Preallocated byte buffers parse kernel lines without garbage collector churn. Sub-millisecond CPU overhead.

In-Memory Ring Buffer

Mutex-protected circular slice retaining rolling metric snapshots in ~5.4 MB of RAM. Zero disk write wear.

→
04

Local WebSocket and SSR

Delta-compressed updates pushed directly to the embedded dashboard. All assets bundled inside the 18 MB binary.

18 MB Single Binary
ZERO CLOUD

100% Private Local Metrics

No mandatory cloud accounts, no third-party telemetry pings, and no telemetry ingestion servers. All metric data remains strictly on your own hardware.

IN-MEMORY

Zero Disk Wear Ring Buffer

No continuous disk writes or heavy time-series database engines wearing down local NVMe or SSD storage pools. Fixed-size circular RAM storage handles rolling history.

NON-ROOT

Least-Privilege Security

Runs cleanly as an unprivileged user. Standard procfs files require no root elevation, and low network ports bind via Linux CAP_NET_BIND_SERVICE.

Security and Hardening

Engineered for untrusted networks, exposed ports, and strict homelab environments.

Argon2id Password Hashing

OWASP key derivation parameters (m=64MB, t=3, p=4) with strict upper bounds against CPU and memory exhaustion attacks.

Double-Submit CSRF Protection

Cryptographic session tokens with SameSite=Strict and HttpOnly flags blocking unauthorized mutating requests.

WebSocket Origin Verification

Strict Origin and Host header validation preventing Cross-Site WebSocket Hijacking (CSWSH) and brute-force connection flooding.

Automatic Let's Encrypt TLS

Built-in ACME management (crypto/acme/autocert) for automated TLS 1.3 certificates without requiring a reverse proxy.

Non-Root User Execution

Runs under an unprivileged user account. Binds low ports (80/443) cleanly using Linux CAP_NET_BIND_SERVICE capabilities.

Hardened Systemd Unit

Includes service hardening directives (ProtectSystem=strict, ProtectHome=true, NoNewPrivileges=true) by default.

Homelab Deployment Guides 
# docker-compose.yml: Mount host /proc and /sys in read-only mode
services:
  statix:
    image: woffluon/statix:latest
    container_name: statix
    restart: unless-stopped
    ports:
      - "8080:8080"
    volumes:
      - /proc:/host/proc:ro
      - /sys:/host/sys:ro
    environment:
      - STATIX_PROCFS_ROOT=/host/proc
      - STATIX_SYSFS_ROOT=/host/sys
# 1. Install and start the hardened systemd service:
curl -sSL https://raw.githubusercontent.com/Woffluon/Statix/main/deploy/install.sh | sudo bash

# 2. Check service status:
sudo systemctl status statix

# 3. Complete clean uninstall and purge:
sudo systemctl stop statix 2>/dev/null || true && sudo systemctl disable statix 2>/dev/null || true
sudo rm -f /etc/systemd/system/statix.service && sudo systemctl daemon-reload
sudo rm -f /usr/local/bin/statix && sudo rm -rf /etc/statix && sudo userdel statix 2>/dev/null || true
# Make the binary executable and start the server:
chmod +x statix-linux-amd64
./statix-linux-amd64 --addr 0.0.0.0:8080
