Engineered for Extreme Efficiency

Designed to monitor Linux systems without stealing CPU cycles or memory from your workloads.

Direct /proc Parsing

Zero reflection, zero heavy cross-platform abstraction wrappers. Directly reads Linux kernel interfaces for instantaneous metric accuracy.

Single Static Binary

Compiled with CGO_ENABLED=0. All templates, CSS, and JS libraries are embedded inside the binary via go:embed.

Hardened Security

Argon2id password hashing (OWASP 2023 specs), HTTP-only SameSite=Strict session cookies, CSRF protection, and sliding-window IP rate limiting.

Native Docker Support

Includes multi-stage Dockerfile and Docker Compose setup for instant deployment in containerized environments.

In-Memory Ring Buffer

Fixed-capacity circular slice protected by sync.RWMutex stores 6 hours of metric history (10,800 snapshots) in ~5.4 MB RAM.

Hardened Systemd Service

Automated installer provisions a system user with CAP_NET_BIND_SERVICE, ProtectSystem=strict, and NoNewPrivileges=true.
